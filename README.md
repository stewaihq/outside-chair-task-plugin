# Outside Chair — Task

Outside Chair — Task governs material commitments, not everyday to-dos. It makes
the person making the promise, the person accepting the result, the deliverable
and final evidence explicit, then surfaces only uncertainty, disagreement or an
intervention that needs judgment.

It works for one person holding both roles and for different people working
through their own agents. The loop is **FRAME → COMMIT → ASSURE → REVIEW**.

Install it for ChatGPT or Codex with `outside-chair-task-chatgpt-0.1.10.zip`, or
for Claude with `outside-chair-task-claude-0.1.10.zip`. Both packages connect to
the same Task-only endpoint and shared Outside Chair account. Start with one
important result: define what counts as done, agree it under each person’s own
identity, attach the final evidence, then accept, repair, reframe or stop.

This independently installable plugin connects to the shared Outside Chair
identity platform but has its own OAuth resource, scopes, ten-tool catalogue,
records and release lifecycle.
